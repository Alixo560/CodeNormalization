> # 可视化辅助

定义为：”代码理解“任务

“即使代码错了，也尽量保留其原始意图”

------

#### 采用“保守规范化”

**系统原则应该是：“不改变算法意图，仅增强语义表达”**

即：

| 操作                 | 是否允许  |
| -------------------- | --------- |
| 改命名               | ✅         |
| 改格式               | ✅         |
| 添加注释             | ✅         |
| 添加可视化标签       | ✅         |
| 自动修复明显格式错误 | ✅         |
| 修改算法逻辑         | ❌（默认） |
| 自动优化算法         | ❌         |
| 改变复杂度           | ❌         |

------

> #### 例子
>
> 学生写：
>
> ```cpp
> while (p != NULL) {
>     p = p->next->next;
> }
> ```
>
> ------
>
> 规范化后
>
> ```cpp
> while (current != nullptr) {
>     current = current->next->next;
> }
> ```
>
> ------
>
> 添加解释
>
> ```text
> 检测到当前节点每次移动两个节点，
> 可能表示学生正在实现“快指针”逻辑。
> ```
>
> ------
>
> 但不自动修复 bug
>
> ```cpp
> current->next
> ```
>
> 可能为空。
>
> ------
>
> 交给可视化系统
>
> 展示：
>
> ```text
> current 跳过节点后发生空指针访问
> ```

------

#### 核心思想

**关注代码语义显式化**

即：

- 学生真实意图
- 数据结构语义
- 算法行为
- 可视化友好性

------

#### 可参考的方向

##### 1. 数据结构语义识别

自动识别：

- 链表遍历
- DFS
- BFS
- 快慢指针
- 递归树遍历
- 并查集

------

##### 2. 学生意图推断

例如：

```text
该代码疑似在实现：
- 二叉树前序遍历
- 链表反转
- 快排 partition
```

------

##### 3. 语义增强 IR（中间表示）

规范化后生成：

```json
{
  "role": "current_node",
  "structure": "linked_list",
  "operation": "traversal"
}
```

然后：

- 可视化
- 自动讲解
- 错误分析

都会变容易。
