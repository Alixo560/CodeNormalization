# 数据结构领域命名规范库（教学版 v0.1）

------

# 1. 通用规范（所有数据结构）

这是最高优先级。

| 类型     | 推荐规范            | 示例                 |
| -------- | ------------------- | -------------------- |
| 类名     | PascalCase          | `LinkedList`         |
| 函数名   | PascalCase          | `InsertNode()`       |
| 普通变量 | snake_case          | `node_count`         |
| 成员变量 | snake_case_         | `head_`              |
| 常量     | kPascalCase         | `kMaxSize`           |
| 指针变量 | 尽量体现语义        | `current` 而不是 `p` |
| bool变量 | 用 is/has/can 开头  | `is_empty`           |
| 不允许   | using namespace std | `std::vector<int>`   |

------

# 2. 链表（Linked List）

------

## 标准节点命名

| 语义     | 推荐命名             | 不推荐 |
| -------- | -------------------- | ------ |
| 当前节点 | `current` / `cur`    | `p`    |
| 前驱节点 | `prev`               | `q`    |
| 后继节点 | `next_node` / `next` | `t`    |
| 头节点   | `head`               | `h`    |
| 尾节点   | `tail`               | `tt`   |
| 新节点   | `new_node`           | `x`    |

------

## 标准操作命名

| 操作 | 推荐函数名       |
| ---- | ---------------- |
| 插入 | `InsertNode()`   |
| 删除 | `DeleteNode()`   |
| 遍历 | `TraverseList()` |
| 查找 | `FindNode()`     |
| 反转 | `ReverseList()`  |

------

## 推荐遍历写法

```cpp
while (current != nullptr) {
    current = current->next;
}
```

------

## 教学语义标签（给可视化系统）

| 行为      | 标签             |
| --------- | ---------------- |
| 单步移动  | `LIST_TRAVERSAL` |
| 双步移动  | `FAST_POINTER`   |
| 修改 next | `LINK_RECONNECT` |
| head变化  | `HEAD_UPDATE`    |

------

| 操作     | 推荐函数名  |

# 6. 数组与广义表

------

## 推荐命名

| 语义     | 推荐命名 |
| -------- | -------- |
| 行数     | `rows`   |
| 列数     | `cols`   |
| 当前下标 | `index`  |
| 数组长度 | `size`   |

------

## 二维数组遍历

```cpp
for (int row = 0; row < rows; ++row)
```

避免：

```cpp
for (int i=0;i<n;i++)
```

在教学代码里更推荐语义化。

------

## 教学语义标签

| 行为     | 标签               |
| -------- | ------------------ |
| 下标访问 | `ARRAY_ACCESS`     |
| 行遍历   | `ROW_TRAVERSAL`    |
| 列遍历   | `COLUMN_TRAVERSAL` |
